# Emberline — Methods

Harmonized burning-activity record for Corrientes, Argentina, from NASA FIRMS MODIS and VIIRS active-fire
detections. Every number in the app is derived from FIRMS files downloaded by `pipeline/fetch_firms.py`
or from a cited official document. Days without satellite coverage are **no data**, never zero.

## 1. Data

- FIRMS area API, bbox W,S,E,N = -60.0, -31.0, -55.5, -27.0 (covers the province: bounds
  W -59.621, S -30.591, E -55.610, N -27.302), clipped to the geoBoundaries ADM1 Corrientes polygon + 0.05°.
- Products: MODIS_SP (2000-11-01 → 2026-08-31) + MODIS_NRT (after), VIIRS_SNPP_SP/NRT,
  VIIRS_NOAA20_SP/NRT, VIIRS_NOAA21_SP/NRT. SP is used up to its last date and NRT strictly after it.
- **Suomi NPP last data date (FIRMS data_availability, queried 2026-11-14): 2026-11-02.** After that, the
  VIIRS reference automatically becomes NOAA-20.
- Missing-data days per platform: FIRMS missing-data table (`/api/missing_data/`), 178 platform-days.
  These are UTC dates and are applied to the same local solar date (≤ 4 h shift in this region).
- A platform-day is **observed** only if it lies within the platform's data range, is not on the
  missing-data list, and its chunk was downloaded successfully (failed downloads become no data, not zero).
  Aqua MODIS is treated as observed from 2002-07-04.
- Boundaries: geoBoundaries gbOpen ARG ADM1/ADM2. Note: the ADM2 layer has no polygon for the
  San Luis del Palmar department, so 24 department presets are offered; province-level results are unaffected.

## 2. Normalization (§4.3)

Common schema for both sensors; local solar date = UTC + lon/15 h, used for all daily aggregation.
Confidence: MODIS <30 low, 30–79 nominal, ≥80 high; VIIRS l/n/h. Default analysis filter: type null or 0
(vegetation fire) and confidence ≠ low. Exact duplicates on (platform, lat, lon, acq_utc) are dropped, SP wins.

## 3. Overlap resolution and the harmonized unit

| Level | Overlap | Resolution |
|---|---|---|
| L1 | duplicate rows (SP/NRT, chunk edges) | exact dedup |
| L2 | one fire → several pixels in one overpass | presence per 0.02° grid cell per day |
| L3 | same fire seen by several platforms that day | presence per cell-day across platforms |
| L4 | same fire on consecutive days | fire events (8-neighbour, ≤1-day gap, union-find) |

**Burning cells** on day *d* = number of 0.02° (~2.2 km) cells with ≥1 detection. Exactly one VIIRS
platform is used per day (SNPP > NOAA-20 > NOAA-21, highest-priority platform observed that day).

## 4. Bridging the sensors (§5.4)

| Era | Available | H_d | Provenance |
|---|---|---|---|
| A | MODIS only | k_M(month) · MODIS cells | estimated |
| B | both | union of MODIS and VIIRS cells | observed |
| C | VIIRS only | k_V(month) · VIIRS cells | estimated |
| — | neither | null | no data |

k_M(m) = Σ union / Σ MODIS cells and k_V(m) = Σ union / Σ VIIRS cells over era-B days, per calendar month.
Uncertainty: year-block bootstrap (500 draws) → 5th/95th percentile of k → H_low/H_high for estimated days.
For a user AOI: k = (n_aoi·k_aoi + 200·k_region)/(n_aoi + 200).

## 5. Alert rule — PRE-REGISTERED

**Recorded 2026-11-14 20:48 UTC, before any FIRMS data for the region had been processed, and before the
2022 event was examined.** The parameters live in `pipeline/config.py::ALERT_RULE` and will not be tuned.

- Signal S_d = 7-day rolling sum of harmonized burning cells H_d in the AOI (trailing window, days d-6…d).
- Baseline: for each day-of-year, pool S values from **2003–2021** within ±15 days of that day-of-year.
  Thresholds P90 and P99 per day-of-year.
- **Alert:** S_d > P90 on 3 consecutive days (alert date = the 3rd day).
  **Severe:** S_d > P99 on 3 consecutive days.
- Activity status (app badge): Normal (S ≤ P90 or rule not met) · Elevated (Alert) · Extreme (Severe) ·
  No data (any day in the 7-day window unobserved).
- Backtest: Corrientes ADM1 polygon, season 2021-11-01 → 2022-03-31; first Alert/Severe date compared with
  official decree dates (lead/lag in days, no causal claim). Honesty check: the same rule is run on every
  season 2003–2021 (Nov 1 → Mar 31) and the number of seasons that triggered Alert/Severe is reported.
  Note: the 2003–2021 seasons are also inside the baseline, so this is an in-sample false-alarm rate.
